# Frontend — Minimarket Mamá

Interfaz completa construida con Next.js, React, JavaScript y Tailwind CSS.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abre `http://localhost:3000`.

Acceso de demostración: `admin@minimarket.pe` / `123456`.

Si el backend de `http://localhost:4000` no está disponible, la interfaz funciona automáticamente con datos locales de demostración.
