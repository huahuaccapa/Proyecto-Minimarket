# 📌 Descripción

**Proyecto Minimarket Mamá** es una plataforma web desarrollada para digitalizar y centralizar las operaciones principales de un minimarket.

El sistema permite gestionar:

- 🛒 Ventas
- 💵 Caja
- 📦 Productos
- 📊 Inventario
- 🚚 Compras
- 🏢 Proveedores
- 👥 Clientes
- 💳 Ventas al crédito
- 💸 Gastos
- 📈 Reportes
- 👤 Usuarios
- ⚙️ Configuración del negocio

El proyecto utiliza una arquitectura separada entre **frontend**, **backend** y **base de datos**, facilitando su mantenimiento, despliegue y crecimiento.
