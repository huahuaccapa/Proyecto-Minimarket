# Backend — Minimarket Mamá

API REST construida con Node.js, Express y JavaScript.

```bash
npm install
cp .env.example .env
npm run dev
```

La API estará en `http://localhost:4000/api`. Ejecuta las pruebas con:

```bash
npm test
```

En esta etapa los datos viven en memoria y se reinician al apagar el servidor. Los endpoints están documentados en `API.md`.
